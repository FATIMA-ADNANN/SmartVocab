# SmartVocab 📘

SmartVocab is an English vocabulary learning application developed as part of the Visual Programming course.  
It is designed to help beginners improve their vocabulary through an interactive and user-friendly interface.

## 🎯 Objectives
- Help users learn new English words
- Provide meanings and examples
- Make vocabulary learning simple and engaging

## 🛠 Technologies Used
- C#
- Windows Forms
- Visual Studio
- SQL Database (if applicable)

## ✨ Features
- Simple and beginner-friendly UI
- Organized vocabulary structure
- Easy navigation

## 📂 Project Status
This project is currently under development and may be improved with additional features in the future.
